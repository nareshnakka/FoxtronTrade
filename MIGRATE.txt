FoxtronTrade — migrate / other laptop
=====================================

Only 4 bats (use these):
  Setup.bat   — install Python/.venv + restore options DB (auto)
  Start.bat   — start 24x7 engine (runs Setup if needed)
  Stop.bat    — stop engine / dashboard
  Update.bat  — pull latest from GitHub (git or ZIP fallback), then Setup

1) Extract / clone anywhere
   (example: D:\FoxtronTrade)

2) Put your .env here (Kite API + TOTP). access_token.json optional.

3) Double-click  Setup.bat  once
   - If no Python 3.11-3.13: downloads official embeddable Python zip into runtime\Python312
     (no admin, no EXE installer — just extract)
   - Creates .venv when possible, else uses portable Python directly
   - Restores options DB from data\option_chain_live\chain.db.zip

4) Double-click  Start.bat
   - Dashboard: http://127.0.0.1:5050
   - Leave window open for 24x7

5) Double-click  Stop.bat  to stop

6) Bug fixes: double-click  Update.bat  then  Start.bat

What is kept local (never overwritten by Update)
-----------------------------------------------
- .env
- access_token.json
- .venv / runtime
- data\option_chain_live\chain.db (live DB)
- data\trades.json

New laptop checklist
--------------------
- Keep laptop plugged in
- Windows Sleep = Never (while plugged in)
- Leave Start.bat window open for 24x7
- Zerodha redirect URL: http://127.0.0.1:5000/callback
